# 📊 EDA on Retail Sales Data

**Track:** Data Analytics (Oasis Infobyte SIP)
**Level:** Level 1 — Task 1
**Author:** Udhayveer Singh Jamwal

## 🎯 Objective
Perform a thorough Exploratory Data Analysis on a retail sales dataset to uncover patterns, customer behaviour trends, and actionable business insights.

## 🛠️ Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset
Retail Sales Dataset — 1,000 individual customer transactions containing:
- Transaction ID, Date
- Customer ID, Gender, Age
- Product Category (Beauty, Clothing, Electronics)
- Quantity, Price per Unit, Total Amount

## 🔍 What's Inside
- Initial data inspection (shape, dtypes, nulls, duplicates)
- Descriptive statistics (mean, median, mode, std) for all numerical columns
- Monthly & Quarterly sales trend analysis (line charts)
- Customer demographics analysis — Age Group distribution & Gender breakdown
- Product analysis — Top-selling category/age-group segments & revenue by category
- Correlation heatmap between numerical variables
- Additional insight — Age Group vs Product Category spending cross-tab heatmap
- Markdown observations after every visualization
- Conclusion with 3 actionable business recommendations

## 📈 Key Insights
1. The 26–45 age bracket forms the largest share of the customer base.
2. Q2 emerged as the strongest sales quarter, suggesting a seasonal opportunity.
3. Total spend is most strongly driven by Price per Unit rather than Quantity or Age.
4. Certain age groups show clear category affinity (revealed only via cross-tab analysis).

## 🚀 How to Run
1. Open `EDA_Retail_Sales.ipynb` in Jupyter Notebook, VS Code, or Google Colab.
2. Ensure `retail_sales_dataset.csv` is in the same directory (or uploaded alongside, if using Colab).
3. Run all cells sequentially.
